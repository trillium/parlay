# parlay-input

Unscoped alias for [`@parlay/input`](../input), held to claim the
`parlay-input` name on the public npm registry. It re-exports
`@parlay/input`'s full public surface and nothing else.

Install `@parlay/input` directly — this package exists only as a pointer to
it for anyone who lands on the unscoped name.

```sh
npm install @parlay/input
```
